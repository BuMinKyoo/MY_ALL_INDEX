# Computer Graphics 기초이론
  - 점과 백터
    - 그래픽스에서는 점과 백터의 표현을 달리하며, 점은 이동할수 있고 백터는 이동할수 없다
    - 각각의 동차 좌표 표현
      - 점 : (x,y,z)	-> (x,y,z,1)
      - 벡터 : (x,y,z)	-> (x,y,z,0)
