# Computer Graphics
  - MFC와 Dear ImGui 비교
    - ImGui는 실행 중인 프로그램의 상태를 확인하거나 값을 조절하는 개발용 GUI를 빠르게 만들 때 주로 사용

<br/>

```text
구분        MFC                              Dear ImGui
----------  -------------------------------  ----------------------------------
주된 용도   Windows 데스크톱 프로그램         게임·그래픽 프로그램의 개발 도구
UI 구성     창과 컨트롤 생성 후 이벤트 처리   매 프레임 코드로 UI 선언
화면 표시   Windows 컨트롤 중심              그래픽 렌더러로 UI를 그림
플랫폼      Windows                          여러 플랫폼 지원
```
